# Thread Focus для BB

Thread Focus дополняет боковую панель BB поиском по проектам и тредам, сворачиваемыми группами проектов и списками тредов, которые требуют внимания.

## Установка

Нужны BB 0.49 или новее, SDK 0.6.132 или новее и включённый штатный плагин **Thread list**. Thread Focus работает в настольном приложении и веб-клиенте BB.

```sh
bb plugin install https://github.com/IvanLeviathan/bb-plugin-thread-focus
```

Чтобы обновить плагин, запустите `bb plugin update bb-plugin-thread-focus`. Включить или отключить его можно в **Settings → Plugins → Thread Focus**.

## Что меняется в боковой панели

- **Поиск** находит проекты и треды, в том числе в свёрнутых проектах. В одном запросе можно сочетать слова из названия проекта и заголовка треда. Регистр и различие `е` и `ё` игнорируются. Нажмите `Esc`, чтобы очистить поиск.
- **«Нужно ваше действие»** показывает видимые активные треды с вопросами и запросами подтверждения. Жёлтый индикатор обозначает ожидание пользователя, зелёный — выполняющуюся работу. После ответа тред возвращается на своё место.
- **«Завершённые»** показывает непрочитанные результаты, включая ошибки. После открытия тред возвращается в проект или список закреплённых.
- **Оформление** добавляет цветные монограммы проектов, названия проектов под закреплёнными тредами и время с последнего сообщения пользователя или ассистента (`<1м`, `5м`, `3ч`, `2д`). Точную дату можно увидеть в подсказке.

Иконки провайдера настраиваются в **Thread list → Rows → Provider icons**.

## Группы проектов

Нажмите кнопку с папкой рядом с поиском, чтобы создать группу, выбрать проекты и указать метки окружений. Группу можно свернуть целиком, а её название и метки доступны в поиске. Состояние сворачивания сохраняется в браузере или настольном приложении.

Тот же параметр доступен в **Settings → Installed plugins → Thread Focus → Группы проектов**. Каждая строка задаёт группу. Разделяйте название группы и названия или ID проектов символом `|`. Метки после двоеточия необязательны.

```text
Портал | dev.example.com: Dev | portal.example.com: Prod
```

## Разработка

```sh
npm ci --include=dev
npm run typecheck
npm test
bb plugin build .
bb plugin install .
```

Оформление опирается на атрибуты `data-sidebar-*` штатного списка тредов. Если структура панели меняется в новой версии BB, проверьте селекторы в `sidebar.ts`.
